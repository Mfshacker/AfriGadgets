# Documentation

The root `README.md` explains the repository and how to run it.

`STYLE-GUIDE.md` records the colours, type, CSS layout, components, and frontend conventions used by AfriGadgets.

`AUTHENTICATION.md` explains the Supabase admin login, local configuration, session guard, logout, and the limits of frontend-only security.

README files in the project folders explain the files held in each area and provide notes for contributors.
