# Storefront Pages

Customer-facing HTML pages live here. The root `index.html` remains the homepage entry point.

Pages in this folder include the shop, product, cart, checkout, About, Contact, FAQ, confirmation, offers, new products, delivery, returns, privacy, and track-order views, plus `login.html`, `signup.html`, and `account.html` for customer accounts.

Paths in these files are relative to `pages/`, so shared assets use `../css`, `../js`, and `../images`. Keep new page links relative to this folder.
