# Storefront Styles

This folder contains the styles used by the customer-facing store.

- `style.css` is the shared import manifest.
- `foundation.css` contains variables, reset, and base element rules.
- `shared.css` contains common layout and components.
- `overrides.css` contains active global compatibility rules.
- `pages/` contains styles loaded by individual pages.

Keep `style.css` limited to imports. Page styles are linked by their matching HTML files.
