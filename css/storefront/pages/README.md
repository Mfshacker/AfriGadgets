# Storefront Page Styles

These stylesheets are loaded only by the pages they belong to:

- `shop.css` - catalogue filters and product listing
- `product.css` - product detail layout
- `cart.css` - cart items and totals
- `checkout.css` - checkout and payment sections
- `faq.css` - FAQ accordion and layout
- `content.css` - About and general content pages
- `about.css` - About page adapter for its legacy markup

Shared rules belong in `../shared.css`, not here.
